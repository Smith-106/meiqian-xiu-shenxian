# 全量重写写作规约（spec.md）

适用范围：《你没钱修什么仙》续书 原 256–631 章，由 Opus 5.5 重写。新稿只写入 full_rewrite\draft，不碰正库；写回前另行备份。

## 一、硬指标
1. 对白占比 20%–30%（按中文双引号内字数 / 全章字数计；低于 20% 或高于 30% 均返修）。
2. 篇幅：按卷连续写成长稿，写完后统一断章；每章约 3000 字（容差 2,800–3,300），断点必须落在悬念、反转、未答之问或将至之事上，章尾留钩子。
3. sm_quality 本地门禁 95 分以上，不得命中 SEVERE 项，不用格言式收尾。
4. 中性文学五维尽量拉高：可读性、人物、推进、画面、节奏；以试点 v2（中性均分 61.0）为底线，目标 70+。
5. 本书铁律五维不得低于原稿（试点基线 97.2 持平即可）：公文冷硬体、册/栏/押/版的规程感保留。

## 二、情节与设定红线
1. 每章情节要点以 beats.json / beats_digest.txt 为准：原章的事件顺序、关键唱词、在场人物、收尾状态必须保留，可合并、可压缩重复仪式，不得删去推进性事件。
2. 11 卷卷纲（outline_continuation.txt）与《设定集》§8.2 旬节律、§8.3 昼夜节律的节点章必须落地：267 一旬讫、270 底联归位、271 堂期已定、306 旬满缴计、310 合封归库、311 启晓候对、348 十日并案候封、350 合卷守晓、371 接更吏首现、381 旬计并案、390 落锁守晓、413 卯十九联点名、430 合梓守晓、470 合匣守晓、480/483/489/499–505 旬与连旬、502 离栈归雾、550 迎晨定卷、575/580、590 合卷出栈、607 影定踏实、615/616、621–627、630 俟编入格、631 廿二落墨。
3. 不新增具名人物、不新增设定；接更吏保持无名、少语（可有极简唱词，但不赋予背景）。
4. 《设定集》§六红线全部遵守：权斗落在册栏押版；阎平死因不改；不重开空位代填；新棱"落格之墨，皆唱其据；凡填凡讫，核由随唱"不删；卯十九不再展开（仅 413、530 两处点名）；苦力与功分保持官僚账法。
5. J 组八大悬丝至终章仍悬：不得回收，也不得新写问责、补恤、复出（黑狗、崔珩、阙、持册人不出场）。
6. 裴琬始终在位，离线/退雾是轮换不是落马；裴琬是择日之手，不持钩；方扁带钩贴白曦腕。

## 三、文风
1. 保留本书术语与仪式味（候对、压据、唱、骑缝、角号、空栏），但每种仪式在一卷内只完整写一次，之后以一两句带过或从新角度写，禁止近乎原样的段落循环。
2. 打破原稿"两句十四字动作 + 唱词 + 四字顿句"的固定节奏；句长、段长交替，加入白曦的内心判断、记忆回闪与具体感官细节。
3. 对白要有来回：唱词之外，人物之间要有问答、试探、沉默后的回应；每章至少一处有张力的对话交锋。
4. 小满、晏吏、裴琬各有口吻：晏吏认命而有良心（"通政司只认结果"），小满手慢而正、话少而实，裴琬短句、不解释。
5. 时间感按"被日子追 → 被旬磨 → 守到天亮"递进，终盘多写晓、晨、天光。

## 四、流程
1. 起点：试点 v2 的 256、257 先把对白补到 20%+，作为全量开篇；300、450、631 的 v2 稿作情节锚点，重写到该处时以其为底再调对白。
2. 按卷写：draft\卷02.txt … 卷11.txt（卷一 256–270 写入 卷01.txt），每卷写完跑 sm_quality 与对白占比自检，不达标先返修再进下一卷。
3. 全书写完后统一断章，生成新章节表（新章号、标题四字为主、字数、对白占比、对应原章号区间）和新旧章号映射 chapter_map.json。
4. 抽样复测：每卷至少 2 章跑本书铁律五维、中性文学五维、成对盲比；不达标的卷返修。
5. 写回正库前再备份，替换 256 往后正文（章数若变化同步 sequence 与前后链），跑 integrity_check；原稿留在 full_rewrite\orig 可随时回滚。
